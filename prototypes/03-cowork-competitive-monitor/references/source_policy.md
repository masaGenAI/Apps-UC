# 出典ポリシー

## 出典ランク（元資料の定義に準拠）

| ランク | 意味 |
|---|---|
| **S** | 政府・公的機関（省庁・社人研・当局発表 等） |
| **A** | 大学・研究機関 |
| **B** | 業界団体・独立第三者・大手報道 |
| **C** | 調査会社・コンサル・ベンダー（数値は当該社推計） |

## ルール

1. **原文リンク必須** — 要約の各項目に一次情報へのリンクを付ける。付けられない情報は載せない（UC-05 誤要約リスク対策）。
2. **数値は一次情報** — 財務・シェア・利用率などの数値は決算資料・公式開示など一次ソースで確認する。二次まとめの数値は根拠にしない（UC-53）。
3. **ランク併記** — 判断に影響する数値・示唆には出典ランク（S/A/B/C）を併記する。C ランクの推計は「当該社推計」と明示。
4. **比較の可否** — 定義・期間・母集団が異なる数値を安易に並べない（apple-to-apple の原則）。
5. **推測の分離** — 事実と推測を必ず分け、推測には「（推測）」を付す。
6. **二モデル検証（G6・任意）** — 重要な示唆は2つの異なるモデルに独立に投げ、相違点のみ人が精査する。
