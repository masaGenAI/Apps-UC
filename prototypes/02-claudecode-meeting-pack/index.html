● Claude Code

会議自動化パック

UC-16 会議自動化（議事録・タスク抽出）／ ★第1波・PT6

文字起こしを入力に、議事録・決定事項・タスク（担当／期限／優先）を1コマンドで生成する Claude Code 向けキット。

ダウンロード / ソース

このキットはコードです。ファイルを取得してローカルで実行します。

⬇ meeting_pack.py 本体・CLI ⬇ sample_transcript.txt サンプル文字起こし 📄 README.md 解説

使い方

# 1) デモ（APIキー不要・オフラインで“形”を確認）
python meeting_pack.py sample_transcript.txt --offline -o out

# 2) 実運用（Claudeで高精度に構造化）
export ANTHROPIC_API_KEY=sk-ant-...
python meeting_pack.py sample_transcript.txt -o out

# 3) 秘匿情報に配慮して人名を匿名化（G1）
python meeting_pack.py sample_transcript.txt --redact -o out

出力は <title>_minutes.md（議事録）と <title>_tasks.json（構造化データ）の2ファイル。後段の自動化（Teams/Planner起票など）に接続できます。

なぜ「Claude Code」で作るのか

UC-16 は適格性テストで ルールA＝チャットで代替不可（Teams＋Power Automate の仕組み構築、録音同意・保存期間の設計、全社標準化が必要）と判定された領域。会話1回で終わらず、コード化・自動化・様式の資産化が要るため、CLI/パイプラインとして書き起こす Claude Code がふさわしい担当です。

ガバナンス原則への対応

原則実装
G5（製品交代に耐える）プロンプト・出力様式を Markdown/JSON の汎用形式で外部化
G1（データ投入区分）--redact で人名を匿名化してから送出（対応表は手元保持）
A1（最終責任は人間）議事録に必ず「レビュー担当」欄を出力し、無断承認を防ぐ
G2（高リスクは人間最終判断）タスク/決定は提案であり、確定は人の承認前提と明記

想定KPI

  • 議事録作成の所要時間削減率（Before実測必須）
  • タスクの取りこぼし率／期限遵守率の改善
  • 会議あたりのフォローアップ漏れ件数
