# Prototype 01 — AI活用 成熟度診断（Claude / Artifacts）

> **元ユースケース：UC-29 AI成熟度診断サービス（外販・◆本命）＋ UC-23 AIケイパビリティ測定キット**
> 7観点・14問で組織のAI活用成熟度を自己診断し、**成熟度レベル・レーダーチャート・優先アクション**を提示する単一HTMLアプリ。

## なぜ「Claude」で作るのか

Claude（claude.ai の Artifacts）は、**自己完結したインタラクティブHTMLをその場で生成・公開**できる。
UC-29 の診断ツールは「クライアントに触ってもらう」体験そのものが価値であり、
1ファイルで動き、リンク共有できる Artifact が最適な器。設問設計（ナレッジ）と併せて Claude の Project 機能で資産化できる。

## 開く

- **公開Artifact**：https://claude.ai/code/artifact/4e85945c-23c2-45a3-a777-dad2b3ddb86d
- **ローカル**：`index.html` をブラウザで開くだけ（依存なし・データ送信なし・ブラウザ内で完結）

## 診断の7観点

元資料の枠組みに直接対応：

| 観点 | 元資料の根拠 |
|---|---|
| 経営の決断 | 経営が決める8論点（D1–D8）— 空いた時間の使い道・課金モデル・統制強度 |
| 測定設計 | Before実測＋二階建て測定（効率化=時間／高度化=代理指標, D8） |
| 業務組込 | 工程分解と適合範囲判定（2-1, G7） |
| 統制・ガバナンス | データ投入区分表（G1）・リスク階層別統制・シャドーAI受け皿（D5, G4） |
| データ資産・評価基盤 | 持続する優位＝自社データ・評価セット・関係（D6） |
| 人材・育成 | ジュニア育成の再設計（D3）— 作業の代替でなく判断力の育成 |
| 基盤・投資配分 | 閉域基盤（A2）・投資配分 10-20-70 |

## 出力

1. **成熟度レベル**（5段階：Ad hoc → Emerging → Structured → Scaling → Advantaged）
2. **総合スコア**（0–100）と **7観点レーダーチャート**（Canvas描画）
3. **最優先の一手**（最弱2観点への具体アクション）＋観点別の推奨アクション
4. 印刷 / PDF保存

## 設計メモ

- 単一HTML・依存ゼロ・オフライン動作・入力データは外部送信しない。
- ライト/ダーク両対応（トークン設計＋テーマ切替）。
- 本診断はプロトタイプ。実際の投資判断には `Before業務の実測` と個別UC選抜（適格性テスト→単一LLMテスト）を併用。
