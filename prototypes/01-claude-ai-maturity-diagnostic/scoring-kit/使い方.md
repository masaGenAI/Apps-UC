# 使い方 — AIリテラシー＆セキュリティ・ガバナンス 採点キット

このキットは「**LLMに読ませて、簡単なプロンプトを打つだけ**」で、あなた（や受講者）の
AIリテラシーとセキュリティ・ガバナンス意識を、世界標準の物差しで採点します。

## セットアップ（どちらか）

### 方法A：Claudeプロジェクトにする（おすすめ・繰り返し使える）
1. Claude で新規プロジェクトを作成。
2. `採点キット_SYSTEM.md` の中身を **プロジェクトのカスタム指示** に貼り付け（または知識ファイルとして `採点キット_SYSTEM.md` と `rubric.json` を添付）。
3. 以後は、対象の文章を貼って送るだけで採点されます。

### 方法B：単発の会話で使う
1. 新しい会話に `採点キット_SYSTEM.md` の中身を貼る。
2. 続けて採点対象を貼り、「採点して」と送る。

## 打つだけの簡単プロンプト例

```
私が書いたプロンプトを採点して：
「〈ここに自分のプロンプトを貼る〉」
```

```
次のシナリオに回答します。採点して：
シナリオ：顧客の契約書をAIでレビューしたい。あなたの進め方を書け。
私の回答：〈ここに回答を貼る〉
```

```
私とAIの会話ログです。私のAIリテラシーとセキュリティ意識を採点して：
〈会話ログを貼る〉
```

- シナリオ課題は `scenarios.md` にあります。セキュリティ・ガバナンス挙動を炙り出す設計です。
- 出力は「人間向けスコアカード」＋末尾に「機械可読JSON」の2部構成で返ります。

## 結果をきれいに可視化したい場合（HTMLハーネス）

1. 採点結果の末尾に出る **JSON部分をコピー**。
2. 同梱の HTML ハーネス（`../index.html`／公開版アーティファクト）を開き、**JSONを貼り付け**。
3. レーダーチャート・危険挙動ハイライト・強み/次の一手つきの**スコアカードが描画**されます（保存も可）。

## 何を測るか（11次元）

- **AIリテラシー（6次元）**：L1 仕組みと限界の理解 / L2 プロンプト設計・タスク分解 / L3 批判的評価・検証 / L4 人間とAIの協働 / L5 倫理・バイアス・社会影響 / L6 適用範囲の判断
- **セキュリティ・ガバナンス意識（5次元）**：S1 データ分類と投入可否 / S2 AI固有脅威の自覚 / S3 人間の最終判断・記録 / S4 規制・契約・著作権 / S5 出力の信頼性統制と外部発信

## 使いどころ（UC-23 / UC-29）

- **UC-23 AIケイパビリティ測定**：研修の前後で採点し、育成投資の効果を測る。
- **UC-29 AI成熟度診断（外販）**：クライアント社員の実力を、世界標準の物差しで可視化する外販商材の中核。

## 注意（G2：人間最終判断）
本採点は人事評価に直結させないでください。育成・自己認識のための目安であり、
1サンプルからの点推定です（複数サンプルでの評価を推奨）。最終判断と記録は人が担います。
