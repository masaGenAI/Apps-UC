このラボの考え方

3プラットフォームは「同じことを別の場所でやる」ものではなく、担当領域が違います。選抜資料の適格性テスト（チャットで済むものはUC化しない）に沿って役割分担しました。
  • Claude … 触ってもらう体験が価値になるもの（採点キット＋可視化アプリ）。
  • Claude Code … コード資産・パイプラインとして持つべきもの（CLI化・自動化）。
  • Claude Cowork … 複数アプリを横断するエージェント作業（収集→検証→要約→配信）。
各プロトタイプは共通原則（G1 データ投入区分／G5 様式の汎用形式化／A1・G2 人間最終判断／G6 二モデル検証）を守っています。
